# 双工作台 B：资源与分析

模式：Operate。用户在对话中明确批准 B。批准效果图：.impeccable/mocks/dual-balanced.png。

## THESIS
让资源管理和分析探索各自完整，同时保留项目、发布版本与选中资源的连续上下文。

## OWN-WORLD
专业 IDE 工作台：窄深蓝导航、浅灰资源树、白色宽内容面；资源树支持折叠、定位、键盘与跳转。

## STORY
选择项目与固定版本，查找资源，阅读类型和定义，追溯来源，带着指标进入分析，再回查口径。

## FIRST VIEWPORT
左侧 64px 全局导航与约 320px 可调整资源树，右侧等权工作区标签、资源页签、名称和分析操作、定义摘要、横向依赖摘要与折叠原始属性。

## FORM
方向 pick，种子 b685865b；构图 B，浅灰 #F3F5F8、白 #FFFFFF、深蓝 #233247、蓝 #315BC3。所有 UI 以语义 HTML 和运行时数据构建，无上线栅格图片。效果图的虚构账号、资源数量以及重复元数据不进入产品；字段是否存在和依赖关系以接口为准。正常中文使用系统字体，技术名称保持可复制，不以展示字体改变资源标识大小写。

## FINISH
