# 已部署资产逐项授权实施计划

按 [已确认的设计](../specs/2026-11-19-asset-grants-design.md) 实施。使用现有 Spring Boot、PostgreSQL、Flyway 和 React 技术栈。执行范围为指标平台当前工作目录，完成整份计划并验证后提交一个产品仓库 commit。

## 约束与验证重点

dbt-service 是部署事实的权威，业务数据库持久化资产归属、用户授权与固定构建的成员关系。同一稳定键可以对应多个构建。资产移除只影响可用性，管理者主动撤销才移除用户使用权。

重点验证跨租户同名、同模型外的重名维度、旧构建迟到、资产移除期间撤销、通过筛选或预览绕开授权这五种情形。
